# lpbot

LP-бот для Telegram-аккаунта (GramJS) с VK-клиентом, веб-панелью и окном GUI на Electron.

## Что нужно

- Windows 10/11 (скрипты запуска `.bat`), либо любая ОС с Node.js.
- Node.js 18 или новее (LTS) и npm.
- Свой `api_id` и `api_hash` Telegram: https://my.telegram.org → API development tools.
- Для VK (необязательно): токен пользователя VK и tor на `127.0.0.1:9050`, если оставлен прокси по умолчанию.

## Установка

```bat
cd путь\к\lpbot
npm install
copy config.example.json config.json
copy settings.example.json settings.json
```

`npm install` ставит и Electron (devDependency) — он нужен только для GUI.

## Где лежат настройки

Все файлы ниже лежат в корне проекта, рядом со `script.js`. Файлы с пометкой «секрет» в git не коммитятся (они в `.gitignore`) и никому не пересылаются.

| Файл | Что в нём | Секрет |
|---|---|---|
| `config.json` | `telegramApiId`, `telegramApiHash`, `panelHost`, блок `vk` (см. ниже). Образец — `config.example.json` | да |
| `session.txt` | сессия Telegram, создаётся после первого входа | да |
| `bot_database.sqlite` | БД бота: триггеры, шаблоны, пользователи, состояние VK | да |
| `settings.example.json` | образец настроек без ключей: префикс, флаги, автостатус, кастомные значения, настройки DeepSeek. Лежит в git. `settings.json` создаётся локально копией этого файла (или самим ботом при сохранении настроек), бот перезаписывает его сам; `settings.json` в `.gitignore` и не коммитится | `settings.example.json` — нет; `settings.json` — да (ключ DeepSeek `deepseek.apiKey`) |

Адрес веб-панели в `config.json`:

| Поле | Значение |
|---|---|
| `panelHost` | адрес, на котором слушает панель. По умолчанию `127.0.0.1` — панель доступна только с этого компьютера. `0.0.0.0` открывает её во всю локальную сеть (пароля у панели нет). Порт — 3001 |

Блок `vk` в `config.json`:

| Поле | Значение |
|---|---|
| `userToken` | токен пользователя VK. Пусто — VK-клиент не запускается, бот пишет об этом одну строку в лог |
| `proxy` | прокси для запросов к VK, по умолчанию `socks5h://127.0.0.1:9050` (tor) |
| `prefix` | префикс VK-команд, по умолчанию `*` |
| `trustedIds` | id доверенных VK-пользователей (уровень 1) |

> ⚠️ После команды `дип_ключ` или сохранения ключа в панели ключ DeepSeek оказывается в `settings.json`. Поэтому `settings.json` в `.gitignore`, а в git лежит только `settings.example.json` без ключа.

## Переменные окружения

Необязательные. Если заданы, имеют приоритет над `config.json` и БД.

| Переменная | Что задаёт |
|---|---|
| `TELEGRAM_API_ID` | `api_id` Telegram |
| `TELEGRAM_API_HASH` | `api_hash` Telegram |
| `VK_USER_TOKEN` | токен пользователя VK |
| `OPENROUTER_API_KEY` | ключ OpenRouter для VK-команд `ор` |

Пример для одного запуска в `cmd`:

```bat
set TELEGRAM_API_ID=12345
set TELEGRAM_API_HASH=ваш_hash
node script.js
```

## Запуск бота

```bat
start.bat
```

или `npm start` (то же самое, что `node script.js`).

**Первый вход — только из консоли.** Бот спросит номер телефона, код из Telegram и, если включён, облачный пароль 2FA, и сохранит сессию в `session.txt`. Дальше вход идёт по сессии без вопросов. Через GUI первый вход не пройти: окно не передаёт ввод в консоль бота.

Остановить — `Ctrl+C` в консоли.

## Веб-панель

Запускается вместе с ботом: http://127.0.0.1:3001. По умолчанию слушает только `127.0.0.1` (ключ `panelHost` в `config.json`).

Разделы: главная, настройки, триггеры, шаблоны, команды, DeepSeek, логи, статистика, экспорт.

- Ключ DeepSeek в панели показывается замаскированным; сохранение формы с маской ключ не меняет.
- Экспорт выгружает в JSON триггеры, шаблоны и безопасные настройки (префикс и флаги). Ключи и сессия в экспорт не попадают.
- Логи — последние 500 строк консоли бота, только пока он запущен.

> ⚠️ В панели нет пароля. Не меняйте `panelHost` на `0.0.0.0` и не открывайте порт 3001 наружу (проброс на роутере, firewall).

## GUI

```bat
gui\start_gui.bat
```

Окно Electron запускает и останавливает `script.js` кнопками «Запустить» / «Остановить», показывает его лог и берёт команды и настройки у веб-панели (`http://127.0.0.1:3001`), поэтому эти вкладки работают, только когда бот запущен. Закрытие окна завершает GUI и бота.

## Команды

Префикс TG-команд задаётся в настройках (`*` по умолчанию). Полный актуальный список — `*команды` в Telegram или страница «Команды» в панели.

Межплатформенные команды (только для владельца аккаунта):

- из Telegram в VK: `*вк_[команда]` или `*вк_[peerId]_[команда]`;
- из VK в Telegram: `*тг_[команда]` или `*тг_[chatId]_[команда]`.

Подробно о VK-клиенте — `docs/vk_client_spec.md`.

Файловые команды `*код …` (TG) и `код показать` (VK) не читают, не меняют и не восстанавливают секретные файлы: `session.txt`, `*.session`, `config.json`, `settings.json`, `.env`, `.env.*`, `*.sqlite`, папку `.git` и бэкапы этих файлов в `backups/`. Регистр букв не важен. Список задан в `secret_files.js`.

## Тесты

Тесты запускаются только на Linux (WSL). На Windows их не гоняют.

Все тесты, кроме `panel_host`, идут на заглушках и обязаны запускаться без сети, под `unshare -rn`. В каждом из них первой строкой стоит проверка `tests/_no_network.js`: если у машины есть сетевой интерфейс кроме петли, тест сразу пишет `FAIL сеть доступна` и завершается с кодом 1. Обхода у этой проверки нет.

```sh
for t in auth trigger-time vk_client vk_commands tg_ws startup_log secret_files; do unshare -rn node tests/$t.test.js; done
node tests/panel_host.test.js
```

`panel_host` запускается с сетью: он поднимает панель и проверяет, что она слушает только `127.0.0.1` и не принимает подключения с внешнего интерфейса. Ему нужны установленные `node_modules` (express, ws).
