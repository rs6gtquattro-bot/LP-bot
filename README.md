## 1. Что это за бот и зачем он нужен

**LP Bot** (Long Poll Userbot) — это ваш персональный умный ассистент, который работает прямо от имени вашего профиля в **Telegram** и **ВКонтакте**. 

В отличие от обычных чат-ботов, которым нужно писать в личные сообщения или добавлять в каналы, userbot превращает ваш обычный аккаунт в мощный комбайн автоматизации:

* ⚡ **Мгновенные команды**: выполняйте десятки полезных команд прямо в любом чате (проверка пинга, аналитика чата, очистка сообщений, QR-коды, калькулятор и многое другое).
* 📝 **Автоматические триггеры**: бот сам ответит заготовленной фразой, если кто-то в чате напишет ключевое слово.
* 📁 **Шаблоны сообщений**: сохраняйте длинные тексты, ссылки и медиафайлы и отправляйте их в один клик или короткой командой (например, `.шаб прайс`).
* 🤖 **Нейросеть DeepSeek**: подключите искусственный интеллект для умных консультаций и ответов на вопросы прямо в чатах.
* 🖥️ **Два удобных интерфейса**: управляйте ботом через наглядное приложение на рабочем столе (Electron GUI) или через браузерную веб-панель с графиками и кнопками.
* 🔒 **100% приватность**: бот работает локально на вашем компьютере. Ваши сообщения, ключи и сессии не передаются третьим лицам.

## 2. Быстрый запуск

### Что нужно для запуска:
* Компьютер с **Windows 10/11** (или Linux/macOS).
* Установленный **Node.js** (версия 18 LTS или новее) — скачивается бесплатно с официального сайта: [nodejs.org](https://nodejs.org/).
* Ваши ключи от Telegram (`api_id` и `api_hash`) — [как их получить за 2 минуты](#3-как-получить-api-id-и-api-hash-в-telegram).

---

### Вариант А: Запуск Portable через батники (.bat)

Этот вариант идеально подходит для запуска из исходного кода или распакованного архива.

#### Шаг 1. Установите зависимости
Откройте папку с ботом, зажмите клавишу `Shift`, кликните правой кнопкой мыши по пустому месту в папке и выберите **«Открыть окно PowerShell здесь»** (или «Открыть в терминале»).

Выполните команду:
```bash
npm install
```
Она автоматически скачает все необходимые библиотеки для работы ядра и графического окна.

#### Шаг 2. Создайте файлы конфигурации
В папке с ботом есть образцы настроек. Скопируйте их:
```cmd
copy config.example.json config.json
copy settings.example.json settings.json
```
Откройте файл `config.json` в Блокноте и укажите ваши `telegramApiId` и `telegramApiHash` ([инструкция ниже](#3-как-получить-api-id-и-api-hash-в-telegram)).

#### Шаг 3. Первый запуск и авторизация (Строго в консоли!)
> [!IMPORTANT]
> **Первый вход всегда выполняется через консоль!** Бот должен запросить у вас номер телефона, код подтверждения из Telegram и пароль 2FA. Через графическое окно первый вход пройти нельзя.

Запустите файл:
```cmd
start.bat
```
*(Или введите в консоли `npm start`)*.

1. Консоль спросит номер телефона: введите его в международном формате (например, `+79991234567`).
2. В Telegram придет служебное сообщение с кодом входа — введите полученный код в консоль.
3. Если у вас включен облачный пароль (двухфакторная аутентификация 2FA) — введите его.
4. После успешного входа бот создаст файл `session.txt`. Теперь вход будет происходить мгновенно без повторного ввода паролей!

#### Шаг 4. Запуск графического окна (GUI)
После того как авторизация пройдена, консоль можно свернуть, либо запускать бот через красивое окно приложения:
```cmd
gui\start_gui.bat
```
В окне появятся кнопки **«Запустить бота»** и **«Остановить»**, мониторинг памяти, индикаторы статуса Telegram и VK, а также живой журнал логов.

---

### Вариант Б: Запуск готового релиза (.exe)

Если вы скачали готовый собранный релиз `lpbot.exe`:

1. Поместите `lpbot.exe` в отдельную папку (например, `C:\LP-bot`).
2. Рядом с файлом создайте `config.json` (с вашими `telegramApiId` и `telegramApiHash`) и `settings.json`.
3. **Первый запуск для авторизации**: откройте командную строку в этой папке и выполните:
   ```cmd
   lpbot.exe --console
   ```
   Введите номер телефона и код Telegram, чтобы создался файл сессии `session.txt`.
4. **Повседневный запуск**: просто дважды кликните по файлу `lpbot.exe`. 
   - Запустится графический интерфейс.
   - В трее Windows (рядом с часами) появится иконка бота.
   - Закрытие окна сворачивает приложение в трей. Чтобы выйти полностью — кликните правой кнопкой мыши по иконке в трее и нажмите **«Выход»**.

## 3. Как получить API ID и API Hash в Telegram

Чтобы бот мог безопасно подключиться к вашему аккаунту через официальный протокол Telegram, нужны персональные ключи разработчика. Получить их можно за 2 минуты:

1. Перейдите в браузере на официальный портал разработчиков Telegram: [https://my.telegram.org](https://my.telegram.org).
2. В поле **Phone number** введите номер вашего аккаунта Telegram в международном формате (например, `+79991234567`) и нажмите **Next**.
3. В официальный клиент Telegram вам придет служебный код подтверждения. Скопируйте его, вставьте в поле **Confirmation code** на сайте и нажмите **Sign In**.
4. На открывшейся странице кликните по пункту **«API development tools»**.
5. Если вы открываете этот раздел впервые, появится короткая анкета:
   * **App title**: введите любое имя, например `MyBotClient`.
   * **Short name**: короткое имя латиницей, например `mybotclient`.
   * **Platform**: выберите `Desktop` или `Other`.
   * Нажмите синюю кнопку **Create application** (или «Save changes»).
6. На экране появятся ваши персональные данные:
   * `App api_id`: число из 7–9 цифр (например, `12345678`).
   * `App api_hash`: длинная строка из букв и цифр (например, `0123456789abcdef0123456789abcdef`).
7. Откройте файл `config.json` в папке бота и вставьте эти значения:
   ```json
   {
     "telegramApiId": 12345678,
     "telegramApiHash": "0123456789abcdef0123456789abcdef",
     "panelHost": "127.0.0.1",
     "panelPort": 3005
   }
   ```
8. Сохраните файл (`Ctrl+S`).

> [!CAUTION]
> **Никогда и никому не передавайте ваш `api_hash` и файл `session.txt`!** Это прямой доступ к вашему аккаунту Telegram.

## 4. Как подключить VK (токен и SSH-туннель)

LP Bot умеет работать одновременно в Telegram и ВКонтакте, принимая команды и триггеры с обеих платформ.

### 4.1. Где взять токен пользователя VK
Для работы VK-клиента необходим пользовательский токен с правами на сообщения (`messages` и `offline`).

1. Получите токен через авторизацию (например, через популярные клиенты вроде Kate Mobile или страницу VK OAuth). Токен представляет собой длинную строку, начинающуюся с `vk1.a...`.
2. Укажите токен одним из двух способов:
   * **Способ 1 (Рекомендуемый)**: укажите в файле `config.json` в блоке `"vk"`:
     ```json
     "vk": {
       "userToken": "vk1.a.ваш_токен_здесь",
       "proxy": "socks5h://127.0.0.1:1080",
       "prefix": "*",
       "trustedIds": [12345678]
     }
     ```
   * **Способ 2**: задайте перед запуском переменную окружения в консоли:
     ```cmd
     set VK_USER_TOKEN=vk1.a.ваш_токен_здесь
     ```
3. Если токен VK не указан — VK-клиент просто останется выключенным, не влияя на стабильность работы Telegram.

### 4.2. Как работает SSH-туннель и зачем он нужен
Токен VK привязывается к вашему домашнему IP-адресу. Если бот запущен на стороннем сервере (VDS/VPS), VK может выдать капчу (код 14) или временно заблокировать сессию за подозрительную смену региона.

Для решения этой проблемы в проекте предусмотрен безопасный сетевой туннель (`tools/vk_tunnel.py`):
```
[Бот на сервере] ──> SOCKS5 (127.0.0.1:1080) ──> [SSH-туннель] ──> [Ваш домашний ПК] ──> [Серверы VK]
```
* **Защита от утечек (`fail-closed`)**: бот направляет трафик VK только через локальный прокси `127.0.0.1:1080`. Если туннель прерывается, бот не пойдет в сеть напрямую, предотвращая скомпрометирование токена.
* **Строгий белый список**: через туннель разрешены исключительно домены ВКонтакте (`*.vk.com`, `*.vk.ru`, `*.userapi.com`) и порт 443. Посторонний интернет-трафик через туннель пройти не может.

## 5. Интерфейс: Веб-панель, GUI и настройка префикса

### 5.1. Графическое приложение (Electron GUI)
Запускается через `gui\start_gui.bat` или кликом по `lpbot.exe`.
* **Автономность**: интерфейс полностью независим от внешнего интернета и внешних CDN (все векторные иконки встроены в локальный бандл).
* **Светофор статусов**:
  * 🟢 **Зелёный** — модуль активен и принимает сообщения.
  * 🟡 **Жёлтый** — соединение переподключается или активна пауза антикапчи.
  * 🔴 **Красный** — ошибка сети или сбой туннеля.
  * ⚪ **Серый** — модуль отключен (например, токен VK не задан).

---

### 5.2. Веб-панель в браузере (Порт 3005)
Веб-панель поднимается автоматически при старте бота. Откройте любой браузер и перейдите по ссылке:
👉 **[http://127.0.0.1:3005](http://127.0.0.1:3005)**

#### Разделы веб-панели:
| Раздел | Что в нём можно делать |
|---|---|
| 📊 **Главная (`/`)** | Обзорная сводка: статус аккаунта, аптайм, память, статус VK Long Poll |
| ⚙️ **Настройки (`/settings`)** | Смена префикса, автопрочитывание упоминаний, автостатус, динамическая обложка |
| 🔔 **Триггеры (`/triggers`)** | Добавление фраз-ловушек и вариантов автоматических ответов бота |
| 📁 **Шаблоны (`/templates`)** | Просмотр списка ваших сохраненных шаблонов и счетчика их вызовов |
| 🎯 **Команды (`/commands`)** | Интерактивный справочник со всеми командами бота и быстрым поиском |
| 🤖 **DeepSeek AI (`/deepseek`)** | Настройка API-ключа нейросети, выбор модели (`chat`/`coder`) и тест связи |
| 📋 **Логи (`/logs`)** | Журнал работы в реальном времени с фильтрацией по ошибкам и поиском |
| 📈 **Статистика (`/stats`)** | Графики активности, популярные триггеры, состояние туннеля VK |
| 💾 **Экспорт (`/export`)** | Выгрузка ваших триггеров и шаблонов в один файл JSON для бэкапа |

> [!WARNING]
> В веб-панели намеренно нет пароля для простоты локального использования. Она настроена слушать только локальный компьютер (`127.0.0.1`). **Не меняйте параметр `panelHost` на `0.0.0.0`** и не открывайте порт 3005 в интернет через роутер!

---

### 5.3. Настройка префикса команд (с автозаменой кавычек)
Префикс — это символ, с которого начинается любая команда бота (например, `*пинг` или `.хелп`).

1. Перейдите в веб-панели в раздел **[Настройки](http://127.0.0.1:3005/settings)** (или в GUI на вкладку «Настройки»).
2. В поле **«Префикс команд»** введите от 1 до 3 спецсимволов (по умолчанию используется `*` или `‘`).
3. **Умная автозамена кавычек**:
   На клавиатурах телефонов (iOS/Android) при наборе одинарной кавычки часто автоматически подставляется фигурная кавычка (`’` или `‘`) вместо стандартного апострофа (`'`).
   В LP Bot встроена автоматическая нормализация: бот одинаково распознает любой вариант кавычек (`'`, `‘`, `’`, `ʼ`). Вы не пропустите команду из-за автоисправления клавиатуры!
4. Нажмите кнопку **«Сохранить настройки»**. Префикс обновится мгновенно в Telegram и в VK без перезапуска бота.

## 6. Безопасность и важные файлы

Все персональные данные хранятся локально в корневой папке бота:

| Файл | Назначение | Уровень секретности |
|---|---|---|
| `session.txt` | Ключ авторизованной сессии Telegram | 🔴 **Строго секретно** (никому не передавать) |
| `config.json` | API ID, API Hash и настройки VK | 🔴 **Строго секретно** (содержит токены) |
| `settings.json` | Настройки бота, префикс, ключ DeepSeek | 🔴 **Строго секретно** (содержит ключ AI) |
| `bot_database.sqlite` | Локальная база данных (триггеры, шаблоны) | 🟡 **Личные данные** |
| `settings.example.json` | Пустой образец настроек | 🟢 Безопасный файл |
| `config.example.json` | Пустой образец конфигурации | 🟢 Безопасный файл |

> [!TIP]
> Команды управления кодом через чат (`*код ...` в Telegram и `код показать` в VK) имеют встроенную защиту: они автоматически блокируют любые попытки прочитать, изменить или удалить файлы с секретами и ключами.

## 💡 Полезные команды для быстрого старта

Отправьте эти команды в любой чат Telegram (с вашего аккаунта):
* `*команды` — показать полный интерактивный список всех команд.
* `*тест` — проверить отклик и работоспособность бота.
* `*триггер add привет Привет, чем могу помочь?` — создать простой автоответчик на слово «привет».
* `*шаб + инфо` *(в ответ на любое сообщение)* — сохранить выбранное сообщение как шаблон с именем `инфо`.
* `*шаб инфо` — отправить сохранённый шаблон в чат.
* `*дип Какой сегодня день?` — задать быстрый вопрос нейросети DeepSeek.
