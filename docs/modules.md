# Модули LP Bot — движок 1.0.0

## Этап 1: безопасный переход

`node main.js` создаёт ядро, загружает модули, выдаёт событие `ready` и затем
целиком вызывает `require('./script.js')`. Сам импорт `require('./main.js')`
не запускает бота: экспортируются `createCore(options)` и `start(options)`.
`start.bat` запускает `node main.js` прежним способом.
`node script.js`, `npm start`, `package.json.main` пока не меняются.
Перезапуск рабочего бота — только по отдельному разрешению руководителя.

На этом этапе `modules/` пуст: службы и прежние команды ещё не перенесены.
Команда `движок` зарегистрирована в `core.commands` без префикса; её обработчик
возвращает строку с версией, списками модулей и этой инструкцией. Вызов из TG/VK
подключается на следующих этапах: маршрутизатор должен использовать текущий
`settings.prefix`, а не зашитый символ. Сейчас старый маршрутизатор не изменён.

## Формат

Положи папку с `index.js` в `modules/`, экспортируй объект и перезапусти бота:

```js
module.exports = {
  name: 'example',
  version: '1.0.0',
  engine: '^1.0.0',
  requires: ['messaging', 'telegram'], // имена модулей, не пути файлов
  commands: {
    example: {
      async handler(core, { args, message, chatId, senderId, messageId }) {
        return 'Ответ';
      },
      help: 'Описание команды',
      aliases: ['пример']
    }
  },
  async init(core) {},
  async stop(core) {}
};
```

Для модуля без зависимостей укажи `requires: []`. `commands`, `init`, `stop`
необязательны. `engine` принимает стабильную точную версию `x.y.z` или диапазон
`^x.y.z`; другие выражения и prerelease на этапе 1 отключают модуль.
Новых npm-зависимостей ядру не требуется.

Поиск рекурсивный: в `core/`, `commands/`, `features/`, `vk/`, `panel/` можно
располагать подпапки модулей. Каталог с `index.js` считается одним модулем,
вложенные файлы этого каталога загрузчик отдельно не запускает. Символические
ссылки не обходятся. Зависимости запускаются перед потребителями.
Несовместимая версия, отсутствующая/упавшая зависимость, цикл, ошибка `require`,
повтор имени модуля или ошибка `init` отключают модуль и его зависимых, но не
независимых соседей. При повторе имени модуля отключаются все его экземпляры.

## API

- `core.version` — версия из `package.json`.
- `core.provide(name, value)` / `core.get(name)` — реестр служб; повтор службы
  или неизвестная служба дают явную ошибку.
- `core.command(name, handler, meta)` — реестр команд `Map`; повтор имени,
  в том числе псевдонима, даёт ошибку. Внутри загрузки ошибка отключает модуль;
  вне загрузки исключение получает вызывающий код. Имена чувствительны к регистру.
- `core.commands.get(name)` возвращает `{ handler, ...meta }` либо `undefined`.
  Стандартный вызов: `await entry.handler(core, context)`.
- `core.on(event, fn)` / `await core.emit(event, ...args)` — слушатели вызываются
  сразу по порядку, `await emit` ждёт всех; ошибка одного не мешает остальным. `message`
  передаёт аргументы маршрутизатора; `ready` означает готовность ядра, не вход TG;
  `stop` отправляет `await core.stop()`.
- `core.log(module, text)` — строка `[module] text`; известные префиксы ключей
  и значения с метками token/password/secret/apiKey/apiHash/session маскируются.
  Не передавай секреты даже в этот лог: произвольную строку без метки нельзя
  надёжно распознать. Тексты исключений модулей ядро намеренно не печатает.
- `await core.loadModules(path)` — одноразовая загрузка; без аргумента `modules/`
  рядом с `main.js`. Отсутствующий каталог равнозначен пустому.
- `core.modules.loaded` / `.disabled` — `Map` загруженных модулей / причин отказа.
- `await core.stop()` — однократное событие `stop`, затем остановка загруженных
  модулей в обратном порядке; ошибка одного `stop` не мешает остальным.

При отказе загрузки `stop` модуля вызывается для уборки, затем ядро откатывает
его регистрации команд, служб и слушателей. Это не песочница: изменения внутри
чужих объектов, файлов, сети, таймеров и иных внешних ресурсов модуль обязан
отменить своим `stop`. Инициализация модулей последовательная; не запускай
регистрации в отложенных задачах после завершения `init`.
Ядро этапа 1 не устанавливает обработчики сигналов и не останавливает старый бот.

## Версии

Только X.Y.Z (`^\d+\.\d+\.\d+$`): X — релиз, Y — патчи критических уязвимостей и ошибок, Z — мелкие фиксы. Первый релиз 1.0.0, движок 1.0.0. Модуль с `version` в другом формате не загружается.
